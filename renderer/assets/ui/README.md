# Interfaccia fantasy

Risorse vettoriali originali disegnate nel progetto:

- `frame.svg`: cornice metallica con smussi, rivetti e intarsi dorati. Usata come border-image a nove sezioni per adattarsi ai pannelli e ai pulsanti.
- `parchment.svg`: grana della pergamena con rumore vettoriale e tinta seppia.
- `seal.svg`: sigillo ornamentale dei ritratti.

Nessuna risorsa remota richiesta durante l’uso. I font e le relative licenze si trovano in `../fonts/`.
